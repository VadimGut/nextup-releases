# Nextup releases

Signed and notarized downloads of [Nextup](https://xriz.com/nextup), a Mac menu-bar calendar for Google, Outlook and Apple calendars.

- **Download the latest version:** [Nextup.dmg](https://github.com/VadimGut/nextup-releases/releases/latest/download/Nextup.dmg)
- **Update feed:** the app updates itself through Sparkle from `releases/latest/download/appcast.xml`.

This repository only hosts release files. The source code isn't public. For help, email support@xriz.com.
